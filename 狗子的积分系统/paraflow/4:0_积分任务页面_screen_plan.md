## 积分任务页面
此页面展示用户获取积分的各项任务，包括每日任务和成就任务，鼓励用户通过与狗狗互动和平台活动来赚取积分。

Layout Hierarchy:
- Header (Full-width)
- Main Content Area (Positioned below the header)
  - Left Sidebar (同“用户与狗狗互动主页面”的左侧边栏，显示狗狗简要信息)
  - Central Task Display Area

### Header
顶部导航栏与“用户与狗狗互动主页面”保持一致，显示用户当前的积分余额，并提供进入积分兑换页面的快捷入口。

### Central Task Display Area
此区域以游戏化界面展示各类积分任务。
- **积分余额与总览**: 醒目地展示用户当前拥有的积分数量（可能以金币或骨头图标表示），以及总的积分获取进度或成就点。
- **每日任务区**:
  - **每日签到**: 拟物化的签到按钮，显示今日签到状态和连续签到奖励。
  - **云摸头任务**: 指示用户需完成的云摸头次数及可获得的积分，提供直接跳转至互动主页面的按钮。
  - **远程喂食任务**: 指示用户需完成的远程喂食次数及可获得的积分，提供直接跳转至互动主页面的按钮。
  - **云丰容任务**: 指示用户需完成的云丰容（如“给狗狗一个快递箱”、“给狗狗一个打结毛巾”）次数及可获得的积分。
- **成就任务区**:
  - **成长里程碑**: 列出达成特定亲密度或成长值目标可获得的积分奖励。
  - **首次捐赠奖励**: 提示用户首次捐赠可获得的积分奖励及实物小奖品预览。
  - **其他特殊任务**: 随平台活动更新的限时或特殊任务，提供额外积分。
- **任务完成状态**: 每个任务条目清晰显示其完成状态（未完成/已完成/待领取），并有拟物化的领取按钮。
